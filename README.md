# 📚 Book Store Project

Bu proje, **React** ve **React Router DOM** kullanılarak geliştirilmiş basit ama işlevsel bir **kitap alışveriş uygulamasıdır**. Kullanıcılar kitapları inceleyebilir, sepete ekleyebilir, sepetten çıkarabilir ve alışverişi tamamlayabilir.

---
🌐 Live Demo
👉 [Projeyi Canlı Görüntüle](https://cool-sunburst-d53dd9.netlify.app/)


## 🚀 Özellikler

* 📖 Kitap listeleme
* 🔍 Kitap detay sayfası
* 🛒 Sepete ürün ekleme
* ❌ Sepetten ürün silme
* 💾 Sepet verilerinin **localStorage** ile kalıcı olarak saklanması
* 💰 Sepet toplam tutar hesaplama
* 💳 Checkout (alışverişi tamamlama)
* 🚦 React Router ile sayfa yönlendirme

## 🧱 Kullanılan Teknolojiler

* **React**
* **React Router DOM**
* **JavaScript (ES6+)**
* **CSS**
* **localStorage**


## ▶️ Projeyi Çalıştırma

```bash
npm install
npm run server
npm run dev
``
